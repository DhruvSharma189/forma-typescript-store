# Forma TypeScript Store 🛍️

A modern, responsive e-commerce storefront built with TypeScript, designed to deliver a clean user interface and engaging shopping experience. The project focuses on maintainable code, reusable components, and responsive web design.

## ✨ Features

- 🎨 Modern and clean user interface
- 📱 Responsive design for desktop, tablet, and mobile
- ⚡ Interactive functionality powered by TypeScript
- 🧩 Structured and maintainable code
- 🛒 E-commerce storefront experience
- 🌐 Designed for a smooth browsing experience

## 🛠️ Tech Stack

- **TypeScript** — Type-safe JavaScript development
- **HTML5** — Semantic page structure
- **CSS3** — Styling and responsive layouts
- **Vite** — Development server and build tooling, if configured in the project

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) — use a version compatible with the project
- npm
- Git (optional, for cloning the repository)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/forma-typescript-store.git
   ```

2. Navigate to the project directory:

   ```bash
   cd forma-typescript-store
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

### Production Build

To create a production build, run:

```bash
npm run build
```

To preview the production build locally, run:

```bash
npm run preview
```

*These commands depend on the scripts configured in `package.json`.*
